# Portfólio de Testes - Sauce Demo 

Este projeto reúne os testes manuais que realizei no Sauce Demo, um site de demonstração de loja online. Testei os fluxos de login, carrinho e checkout e documentei os casos de teste executados e os bugs encontrados com prints e videos utilizado a ferramenta jam para capturar e gravar os bugs e erros ocorridos.

## Resumo
- 9 casos de teste executados
- 2 bugs reportados
